# homebrew-tap

Homebrew tap for [@danielriddell21](https://github.com/danielriddell21)'s tools.

## Usage

```bash
brew tap danielriddell21/tap
```

Then install any formula or cask below (the tap prefix lets you skip `brew tap`).
